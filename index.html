PROJECT OVERVIEW

About Bright Path

Bright Path is a student project prototype exploring accessible communication and learning support for children with autism. It demonstrates phrase buttons, browser speech tools, optional self-reported check-ins, a basic focus activity, and a caregiver activity log.

Important limitations

  • This prototype does not diagnose autism or detect emotions automatically.
  • Activity logs are stored in this browser's local storage and may be visible to other users of the same device.
  • Do not enter sensitive personal or medical information.
  • Use with caregiver/educator guidance and adapt the interface to each child's preferences.
  • Speech recognition may not work in every browser or language.

Accessibility choices

Large buttons, clear labels, keyboard focus styles, simple wording, reduced-motion support, and status announcements are included. This is a prototype and should be tested with intended users and accessibility specialists.
